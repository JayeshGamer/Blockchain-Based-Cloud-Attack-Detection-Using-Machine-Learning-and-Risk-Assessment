## 2. Processed Streaming Sample
- `data/processed/stratified_sample.csv.gz`: The 50,000-flow chronologically sorted evaluation sample:
  - **8,445** Monday benign baseline flows (used for zero-leakage warm-up scaling and initialization).
  - **41,555** streaming flows spanning Tuesday–Friday (15,000 attacks, 26,555 benign) used for prequential evaluation under delayed feedback.

---

## 3. Example Inference Demonstration Files
- `data/example_input.csv`: A balanced 50-flow validation batch (25 benign, 25 attacks) formatted exactly according to the 69-feature CICIDS2017 schema.
- `data/example_output.csv`: The verified prediction output generated by `OnlineSGDPredictor` using the default saved checkpoint (`models/online_sgd_final_online.joblib`), containing:
  - `flow_id`: Sequential flow identifier
  - `attack_score`: Continuous monotonic attack score in $[0, 1]$
  - `threshold`: Active decision threshold (0.5000)
  - `prediction`: Binary classification (`0` = Benign, `1` = Attack)
  - `predicted_label`: Categorical label string (`BENIGN` vs `ATTACK`)

---

## 4. Input Requirements & Preprocessing
The model strictly expects precomputed bidirectional network flow statistics. Raw packet captures (PCAP) must first be processed by CICFlowMeter or compatible tools before passing to the predictor.
Missing required features will result in a validation error. Additional metadata columns (e.g. timestamps, source/destination IPs) are ignored automatically during inference.
